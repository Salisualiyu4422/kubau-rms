# Kubau Local Government Revenue Management System

A proposed front-end demonstration for local revenue services, receipt lookup,
and community issue reporting.

> **Prototype only:** This project is not an official council service. It has no
> backend, sign-in, or role-based access controls. Form entries are stored in
> the current browser, and receipt lookups use illustrative sample data. Do not
> enter real, confidential, or sensitive information, and do not treat its
> receipts or records as official.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Project contents

- `index.html` and other HTML files: citizen-facing pages and example user,
  collector, and administrator portals.
- `app.js`: browser-only demonstration interactions and sample data.
- `styles.css`: responsive page styling.
